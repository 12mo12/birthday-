A LITTLE BIRTHDAY SURPRISE — QUICK SETUP

HOW TO PREVIEW
1. Extract the ZIP file into a folder.
2. Keep index.html, style.css, script.js, and the assets folder together.
3. Open index.html in Chrome or another modern browser. If a browser blocks any local behavior, run the folder through a local server (for example VS Code + Live Server, or a local server app on Android).
4. This is a private local preview. It is not published online until you choose to upload it.

ADD YOUR PHOTOS AND AUDIO
Put your own files inside the assets folder and use these exact names:
- gallery-1.jpg through gallery-6.jpg : six photos displayed together like a scrapbook grid on the memories page
- her-eyes.jpg : eyes page
- her-smile.jpg : smile page
- your-song.mp3 : song page
- background-music.mp3 : soft background music that starts after the visitor opens the letter and plays between other audio tracks
- your-voice.mp3 : your own voice recording on the special final page

For more than six gallery photos, duplicate a gallery-slide block in index.html and add a matching dot in the photoDots area; the current six slots work without code changes.
JPG/PNG photos are fine; if you use PNG, change the filename in index.html to match. MP3 is recommended for audio compatibility.

CUSTOMIZE
- Change the browser tab title in the <title> tag in index.html.
- Change the small heading at the top by editing the text inside #siteTitle.
- Colors are centralized near the top of style.css in :root. Adjust --rose, --bg, --gold, --ink, etc.
- The page flow is: Welcome/envelope → photo gallery → eyes → smile → song → compliments → long letter → password-protected gold sea-and-moon message, special date, and voice recording.
- The opening “Happy Birthday” splash fades away automatically. The envelope opens when the visitor presses the button. Flowers and petals float in the background and burst on opening/unlocking the final page.
- The last page password is currently 312026. Change it in script.js by replacing the string 312026.
- The date counter is set to 316 days between 03 Jan 2026 and 15 Nov 2026 (elapsed-day count).
- Navigation buttons only say Back and Next so the following page remains a surprise.
- Browsers usually block autoplay until a user interacts with the page. Background music starts after the visitor taps Open your letter. The background track pauses while the song or voice recording plays, then resumes when it ends or is paused.

NOTES
The browser needs an explicit user tap to play audio; this is normal browser behavior. Google Fonts need an internet connection, but the site has fallback fonts. The images and audio are not included; add your own files with the names above.
